# Заметки по проекту

## Технологии
- Jekyll - генератор статических сайтов
- Skeleton CSS - минималистичный CSS фреймворк
- Normalize.css - сброс стилей браузера

## Структура CSS
- `skeleton.css` - основной фреймворк (сетка 12 колонок, типографика, формы)
- `normalize.css` - сброс стилей браузера  
- `main.css` - кастомные стили проекта

## Команды
```bash
# Запуск
export PATH="$PATH:/home/u/.local/share/gem/ruby/3.2.0/bin" && jekyll serve --host 0.0.0.0 --port 4000

# Остановка
pkill -f jekyll
```
